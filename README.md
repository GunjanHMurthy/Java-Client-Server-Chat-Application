# Java Client-Server Chat Application

## Overview

This project is a real-time chat application developed using Java Socket Programming and Client-Server Architecture. It enables communication between a server and client over a network using TCP sockets.

## Features

* Real-time messaging
* Client-Server communication
* TCP Socket Programming
* Multi-threaded server support
* Console-based interface

## Technologies Used

* Java
* Socket Programming
* TCP/IP Protocol
* Eclipse IDE

## Project Structure

```text
src/
 └── clientserver/
     ├── Client.java
     └── Server.java
```

## How to Run

### Start the Server

1. Open the project in Eclipse.
2. Run `Server.java`.
3. The server starts and waits for client connections.

### Start the Client

1. Run `Client.java`.
2. Connect to the server.
3. Start sending and receiving messages.
